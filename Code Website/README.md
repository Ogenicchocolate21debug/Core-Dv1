# Code Website

Website, browser, UI, and web-operation category.

Routes GOD MODE capabilities for:
- `dom_cdp`, `accessibility`, `input_event`, `vision`, `window`
- browser-based website inspection and operation
- web deployment verification
- Cloudflare/website workflows when an authorized connector or CI surface is available

A cloud/browser execution surface is not treated as equivalent to an unrelated local desktop target.
