# Code System

Core execution and system-operation category.

Routes GOD MODE capabilities for:
- `workspace_*`
- `read_file`, `search_text`, `apply_patch`
- `git_status`, `git_diff`, `git_log`
- `project_dev`, `test`, `lint`, `typecheck`, `build`
- `process_*`, `shell`, `codex_run`
- `system_info`, `health`

Operating contract: read before write, preserve unrelated work, make scoped/reversible changes, and verify results.
