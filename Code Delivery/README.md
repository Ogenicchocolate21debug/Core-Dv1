# Code Delivery

Delivery, deployment, automation, and connector execution category.

Routes GOD MODE capabilities for:
- GitHub/CI and hosted runners
- n8n and authorized cloud execution surfaces
- `notification`, `scheduler`, `web_fetch`
- deployment verification and post-write re-fetch
- outbound calls, authenticated inbound webhooks, or hybrid routing as required

Secrets are referenced by metadata/name only and actual values stay in approved credential UIs or secret managers.
